# homebrew-tap

Homebrew tap for [YapStack](https://github.com/yapstackai/yapstack-releases).

## Install

```bash
brew install yapstackai/tap/yapstack
```

If Homebrew asks for tap trust:

```bash
brew trust --cask yapstackai/tap/yapstack
```

## Upgrade

```bash
brew update
brew upgrade --cask yapstack
```

## Requirements

- macOS (Apple Silicon / arm64)
